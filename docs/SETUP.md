# Запуск Copione: пошаговая инструкция

Порядок такой: сначала приложение запускается на iPhone в демо-режиме (без ключей), потом подключается настоящий каталог фильмов (TMDB), затем аккаунты и друзья (Supabase). Каждый шаг можно делать отдельно.

---

## 0. Что понадобится

- **Компьютер** на Windows, macOS или Linux. Mac для разработки не нужен.
- **Node.js** версии 20 или новее (LTS): скачайте с [nodejs.org](https://nodejs.org) и установите. Проверка в терминале: `node -v`.
- **Git**: [git-scm.com](https://git-scm.com). Можно и без него: на GitHub нажмите **Code → Download ZIP**.
- **iPhone** с приложением **Expo Go** из App Store.

Телефон и компьютер должны быть в одной Wi-Fi-сети (или см. «туннель» ниже).

---

## 1. Скачать проект и установить зависимости

```bash
git clone https://github.com/artyomvorobiov/copione.git
cd copione
npm install
```

> Если код ещё лежит в отдельной ветке, переключитесь на неё: `git checkout claude/great-pascal-9lg0as`.

---

## 2. Запустить на iPhone (демо-режим)

```bash
npx expo start
```

В терминале появится QR-код. Откройте **Камеру** на iPhone, наведите на код и нажмите на всплывшую ссылку: приложение откроется в Expo Go.

Что вы увидите:

- ленту с отзывами демо-сообщества (Аня, Макс, Лена, Дима, Саша);
- встроенный каталог из ~30 известных фильмов и сериалов;
- **настоящую музыку** из Apple Music: поиск, чарты, обложки, превью треков;
- Мэтч, в котором с вами свайпает бот «Кинодруг».

Ваши оценки и отзывы сохраняются на телефоне. Сбросить всё можно в **Настройки → Сбросить демо-данные**.

**Если не открывается:**

- «Could not connect to the server»: телефон и компьютер в разных сетях. Запустите `npx expo start --tunnel`.
- «Project is incompatible with this version of Expo Go»: Expo Go из App Store поддерживает только последнюю версию Expo SDK. Проект сделан на SDK 57. Если Expo Go уже обновился до следующей версии, обновите проект:
  ```bash
  npx expo install expo@latest
  npx expo install --fix
  ```
- Изменения в коде применяются сразу. Перезагрузить приложение можно встряхиванием телефона → **Reload**.

## 3. Настоящий каталог фильмов и сериалов (TMDB)

TMDB — бесплатная база фильмов (её же использует Letterboxd). Ключ выдают сразу.

1. Зарегистрируйтесь на [themoviedb.org](https://www.themoviedb.org/signup) и подтвердите почту.
2. Откройте **Settings → API** ([прямая ссылка](https://www.themoviedb.org/settings/api)) и создайте ключ (тип **Developer**). В анкете можно указать: тип — мобильное приложение, название — Copione, адрес — ссылка на ваш GitHub.
3. Скопируйте **API Read Access Token** (длинный, начинается с `eyJ`) или **API Key**. Подойдёт любой.
4. В папке проекта создайте файл `.env` из шаблона:
   ```bash
   cp .env.example .env        # Windows: copy .env.example .env
   ```
5. Откройте `.env` в любом редакторе и вставьте ключ:
   ```
   EXPO_PUBLIC_TMDB_KEY=eyJhbGciOi...
   ```
6. Перезапустите со сбросом кэша (значения из `.env` встраиваются при сборке):
   ```bash
   npx expo start -c
   ```

Теперь в поиске весь каталог TMDB с постерами, трейлерами, сезонами, рекомендациями и блоком «Где посмотреть».

> Если api.themoviedb.org недоступен в вашей стране, для разработки поможет VPN. Для пользователей можно поднять свой прокси (например, Cloudflare Worker) и указать его в `EXPO_PUBLIC_TMDB_API_BASE` и `EXPO_PUBLIC_TMDB_IMAGE_BASE`.

## 4. Аккаунты, друзья и лента (Supabase)

Supabase — бесплатный бэкенд (база Postgres + регистрация). С ним появляются аккаунты, подписки, лента друзей, комментарии и Мэтч между разными телефонами.

### 4.1. Создать проект

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) → **New project**.
2. Придумайте пароль базы (сохраните его), регион выберите поближе к пользователям, например **Central EU (Frankfurt)**.
3. Подождите 1–2 минуты, пока проект создаётся.

### 4.2. Создать таблицы

1. В меню слева откройте **SQL Editor** → **New query**.
2. Откройте файл `supabase/schema.sql` из проекта, скопируйте **весь** текст и вставьте в редактор.
3. Нажмите **Run**. Должно появиться «Success. No rows returned».

Скрипт можно запускать повторно (например, после обновления приложения), данные он не удаляет.

### 4.3. Настроить вход по почте

**Authentication → Sign In / Providers → Email**:

- **Для тестов выключите «Confirm email»**, тогда регистрация работает мгновенно. Встроенная почта Supabase отправляет всего несколько писем в час, поэтому с включённым подтверждением тестировать неудобно.
- **Перед публикацией** подключите свой SMTP (**Authentication → Emails → SMTP Settings**, например Resend или Postmark) и включите подтверждение обратно.

### 4.4. Ключи в `.env`

На главной странице проекта нажмите **Connect** (или откройте **Project Settings → API Keys**) и скопируйте:

- **Project URL**, вида `https://abcdefgh.supabase.co`;
- **publishable key** (`sb_publishable_...`) или **anon key** из раздела *Legacy API Keys*. Подойдёт любой.

> ⚠️ **Никогда** не вставляйте в приложение `service_role` / `secret` ключ: он даёт полный доступ к базе.

```
EXPO_PUBLIC_SUPABASE_URL=https://abcdefgh.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
```

Перезапустите `npx expo start -c`. Появится экран входа: зарегистрируйтесь, позовите друга, подпишитесь друг на друга и попробуйте Мэтч по коду комнаты.

### 4.5. Модерация

- Жалобы пользователей лежат в **Table Editor → reports** (`target_type` — что, `target_id` — id записи, комментария или профиля).
- Удалить запись или комментарий можно в **Table Editor** (таблицы `entries`, `comments`).
- Заблокировать человека: **Authentication → Users → … → Ban user** или удалить.

Apple требует реагировать на жалобы в течение 24 часов, поэтому заглядывайте туда регулярно.

## 5. Проверка

- [ ] В демо-режиме открывается лента с отзывами, ставятся оценки.
- [ ] С ключом TMDB в поиске находятся любые фильмы, есть постеры.
- [ ] С Supabase появляется экран входа, после регистрации пустая лента и кнопка «Найти людей».
- [ ] Два аккаунта на двух телефонах: подписка, лайк, комментарий, Мэтч по коду.

## Частые проблемы

| Симптом | Что сделать |
|---|---|
| Изменения в `.env` не применились | Перезапустить `npx expo start -c` |
| «Нет связи с сервером» в поиске фильмов | Проверьте ключ TMDB; возможно, TMDB недоступен в вашей сети |
| Музыка долго грузится или выдаёт ошибку | У Apple ограничение ~20 запросов в минуту с одного IP. Подождите минуту |
| «Почта не подтверждена» при входе | Выключите «Confirm email» (п. 4.3) или подтвердите адрес из письма |
| «Слишком много попыток» | Лимит писем Supabase. Подождите или подключите SMTP |
| В вебе (`npx expo start --web`) музыка демонстрационная | Браузеры блокируют iTunes API (CORS), на телефоне всё настоящее. Веб нужен только для быстрых проверок |
| Хочу отладить на компьютере | Нажмите `w` в терминале `expo start`, откроется веб-версия |

```bash
npm test               # юнит-тесты
npm run typecheck      # TypeScript
npm run lint           # ESLint
npm run test:supabase  # интеграционные тесты против локального Supabase (Docker), см. tests/supabase/README.md
```

Тексты интерфейса лежат в `src/i18n/ru.ts` и `src/i18n/en.ts`. При добавлении ключа TypeScript проследит, чтобы перевод был в обоих файлах.
