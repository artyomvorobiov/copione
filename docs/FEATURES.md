# Copione: продукт и идеи развития

## Позиционирование

**Один дневник для всего, что вы смотрите и слушаете.** Letterboxd хорош для фильмов, но там нет сериалов и музыки, нет русского интерфейса, а статистика платная. Для сериалов есть Serializd и TV Time, для музыки RateYourMusic и Musicboard. Copione объединяет всё в одном минималистичном приложении и добавляет социальные механики, которых нет у конкурентов.

## Что уже есть

### Основа (паритет с Letterboxd)
- Оценки с половинками звёзд, лайки, «Хочу посмотреть / послушать».
- Дневник: дата, пересмотр, рецензия, флаг спойлеров.
- Профиль: аватар-эмодзи, «о себе», любимые фильмы и альбомы (до 4), подписчики.
- Подписки, лента друзей с фильтром «Всё / Кино / Музыка», лайки и комментарии к рецензиям.
- Списки, в том числе нумерованные (топы), с перестановкой и шарингом.
- Поиск фильмов, сериалов, альбомов, треков, артистов и людей.
- «Где посмотреть» (данные JustWatch), трейлеры, рекомендации, состав.

### Отличительные фишки
1. **Кино + сериалы + музыка** в одном профиле, одной ленте и одной статистике.
2. **Оценка треков в треклисте** и подсказка «средняя по трекам» для альбома. Такого нет даже у RateYourMusic в мобильном виде.
3. **Саундтрек фильма**: альбом-саундтрек на странице фильма связывает две половины приложения.
4. **Сериалы**: прогресс по сериям, «Продолжить смотреть» с отметкой следующей серии в одно касание, дата новой серии, отзывы о конкретном сезоне.
5. **Мэтч**: совместный выбор фильма свайпами (вдвоём или компанией до 8 человек), общий код комнаты, анимация «Это мэтч!», совпадения можно сразу добавить в «Хочу посмотреть».
6. **Совпадение вкусов**: процент совместимости отдельно по кино и по музыке, «вы оба любите», «главные разногласия». Формула учитывает и близость оценок, и корреляцию, а при малом числе общих оценок не выдаёт ложные 100%.
7. **Вайбы**: эмоциональные теги к записи и сводка аудитории в процентах на странице тайтла.
8. **Слепая оценка** (включена по умолчанию, отключается в настройках).
9. **Защита от спойлеров**, включая автоматическое скрытие отзывов о непросмотренных сезонах.
10. **Под настроение**: подборки по эмоциям вместо жанров.
11. **Карточки для сторис**: отзыв или итоги года картинкой 1080×1920.
12. **Бесплатная статистика**: итоги года, часы, жанры, режиссёры, артисты, распределение оценок, цели на год.
13. **Импорт из Letterboxd** и **экспорт дневника в CSV**: ваши данные остаются вашими.
14. **Демо-режим** без регистрации, с демо-сообществом, чтобы сразу понять, как всё работает.

## Идеи на следующие версии

Отсортировано по соотношению пользы и сложности.

| Идея | Зачем | Как сделать |
|---|---|---|
| Push-уведомления | Новая серия, лайк, комментарий, мэтч | `expo-notifications` + Supabase Edge Functions / Database Webhooks |
| Вход через Apple | Регистрация в одно касание | `expo-apple-authentication` + Supabase Auth (Apple provider) |
| Восстановление пароля | Обязательно для живого продукта | `resetPasswordForEmail` с 6-значным кодом в шаблоне письма |
| Фото-аватары | Профиль живее | `expo-image-picker` + Supabase Storage |
| Realtime в Мэтче | Мгновенные совпадения вместо опроса раз в 2,5 с | Supabase Realtime на таблицу `match_swipes` |
| Виджет iOS «Следующая серия» | Удержание | Нужна dev-сборка (`expo-dev-client`) и нативный target |
| AI-советчик | «Посоветуй фильм под настроение и мои оценки» | Edge Function + LLM, промпт из ваших оценок и вайбов |
| Импорт из Кинопоиска и IMDb | Рост аудитории в России | Парсер их CSV-экспорта (IMDb) или HTML (Кинопоиск) |
| Рецензии-ответы и «полезно» | Глубже обсуждения | Таблицы `review_votes`, треды комментариев |
| Челленджи | «52 альбома за год», «Вся фильмография Нолана» | Списки-челленджи с прогрессом |
| Pro-подписка | Монетизация: темы, расширенная статистика, отметка «Pro» | In-App Purchase (RevenueCat). Помните про коммерческую лицензию TMDB |

## Метрики, за которыми стоит следить

- Доля новых пользователей, сделавших 3+ оценки в первый день (активация).
- Сколько человек подписаны хотя бы на 3 других (сетевой эффект).
- Комнаты Мэтча на пользователя в неделю (вирусность: каждая комната приводит друга).
- Возврат на 7-й и 30-й день.
